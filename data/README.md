# Data (not in git)

```
data/
  raw/
    scb/        one folder per SCB subset, each with its .yaml + images/ + labels/
    dipser/     DIPSER subset (second test set)
  processed/    everything generated by scripts/ (manifest, splits, questions)
```

## SCB-Dataset

- Paper: Yang, *SCB-Dataset*, arXiv:2304.02488. Code: https://github.com/Whiffe/SCB-dataset
- Files: https://huggingface.co/datasets/wintonYF/SCB-Dataset (subset folders + `YOLO.zip`, 5.3 GB)
- Licence: academic research / non-commercial only. Do not redistribute.

Download one subset (example):

```bash
pip install -U huggingface_hub
hf download wintonYF/SCB-Dataset --repo-type dataset \
  --include "SCB5-Discuss-2024-9-17/*" --local-dir data/raw/scb     # `hf` replaces the old huggingface-cli
cd data/raw/scb/SCB5-Discuss-2024-9-17 && unzip -q *.zip && cd -
python scripts/inspect_scb.py --root data/raw/scb
```

Check after unzipping that each subset folder has its `.yaml` next to `images/` and `labels/`.
If the zip unpacks one level deeper, move the `.yaml` to that level.

## DIPSER

- Paper: Marquez-Carpintero et al., arXiv:2502.20209. Licence: CC BY 4.0.
- Labels are attention / emotion, not our behaviours: we hand-label 100–200 frames (test only).

On the NTU cluster, keep data on `/projects/IE4422` and symlink: `ln -s /projects/IE4422/data/raw data/raw`.
