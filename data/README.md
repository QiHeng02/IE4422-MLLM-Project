## SCB-Dataset

- Paper: Yang, *SCB-Dataset*, arXiv:2304.02488. Code: https://github.com/Whiffe/SCB-dataset
- Files: https://huggingface.co/datasets/wintonYF/SCB-Dataset (subset folders). Do not download `YOLO.zip`: it holds YOLO code and teacher-behaviour runs only (decisions #13).
- Licence: academic research / non-commercial only. Do not redistribute.

Download one subset (example):

```bash
pip install -U huggingface_hub
hf download wintonYF/SCB-Dataset --repo-type dataset \
  --include "SCB5-Discuss-2024-9-17/*" --local-dir data/raw/scb     # `hf` replaces the old huggingface-cli
cd data/raw/scb/SCB5-Discuss-2024-9-17 && unzip -q *.zip && cd -
python scripts/inspect_scb.py --root data/raw/scb
```

The scripts search below the folder that holds each `.yaml`, so nested `images/` and `labels/` folders are fine
(SCB unpacks to `<subset>/<subset>/images/`). They skip the `exp/` folders of YOLO training output.

We use 3 subsets: `SCB5-Discuss-2024-9-17`, `SCB_BowTurnHead_20250509`, `SCB5-Handrise-Read-write-2024-9-17`.
Download each with its own `hf download` command; several `--include` patterns in one command do not work as expected.

## Roboflow exam_cheating (exam photos; being checked, Task 2a)

- https://universe.roboflow.com/behavior-cheating/exam_cheating-keaor · CC BY 4.0 · ~1,000 images
- Classes: Use_phone, Look_around, Cheat_paper, Normal
- Download with a free Roboflow account in **YOLOv8** format into `data/raw/scb/exam_cheating/`.
  Choose a dataset version **without augmentation** if there is one: augmented copies of one photo must not end up in both training and test (PROJECT_PLAN D6).
- Check that the export's `data.yaml` lists `names`. Then run `inspect_scb.py` and `preview_class.py` on it, as for SCB.

## DIPSER

- Paper: Marquez-Carpintero et al., arXiv:2502.20209. Licence: CC BY 4.0.
- Labels are attention / emotion, not our behaviours: using it means labelling 100–200 frames by hand (test only). Optional (PROJECT_PLAN D5).
